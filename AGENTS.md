# How to FL — working notes

A student-written guide for the **Future Leaders International Undergraduate Double Degree
Programme** at Peking University (Guanghua). Written by Cohort 6 for Cohort 7 and everyone
after. The deadline that matters: **Cohort 7 lands September 2026.**

**Live:** https://how-to-fl.github.io · **Repo:** `how-to-fl/how-to-fl.github.io` (public,
org-owned) · deploys automatically on push to `main`.

Read this before changing anything. Several things below look wrong and are load-bearing —
three of them break the map *silently*, with no error in the console.

---

## Voice

The site speaks as **we/us** (the cohorts writing it) to **you** (the reader). Informal,
direct, warm, specific. Never third-person "students should" or "the cohorts". This applies
to page copy, UI notices, issue forms, CONTRIBUTING and README.

> "On a Beijing connection it often won't load, and that's not your problem to fix."

Short and specific beats long and vague. Say when we're unsure. No political commentary, and
VPN content stays **descriptive, not instructional**.

## The two rules the build enforces

**1. Everything is same-origin.** No CDNs, no Google Fonts, no `raw.githubusercontent.com`.
A third-party origin can be blocked independently of us, and blocked assets don't degrade —
they hang. `scripts/validate.mjs` enforces this with an **allowlist** over asset-loading
contexts. `static.cloudflareinsights.com` is the single documented exception. Ordinary
hyperlinks are fine; fetching from another host is not.

**2. Coordinates are WGS-84 only.** Amap/Tencent use GCJ-02, Baidu uses BD-09. Anything
copied from either lands 300–500 m out.

> **Never invent coordinates.** Two seeded pins were written from memory and were **633 m
> and 505 m wrong**. The CI bbox check will *not* catch an error of a few hundred metres.
> Look them up (Nominatim, bounded to Beijing) or leave them blank. The admin panel's
> "Find these coordinates for me" button does exactly this.

## Traps that cost hours — do not "fix" these

**MapLibre must not be bundled.** It resolves its Web Worker from its own `import.meta.url`.
Bundling breaks the handshake and the map hangs on a blank canvas **with no error at all**.
It's served unbundled from `public/vendor/` by `scripts/sync-vendor.mjs` (runs on
`predev`/`prebuild`; output gitignored). The `@vite-ignore` dynamic import is deliberate.

**Sprite and glyph URLs must be absolute, built by string concatenation.** MapLibre 6
rejects a root-relative sprite URL and that aborts the *entire* style load. Do not use
`new URL()` — it percent-encodes the `{fontstack}` / `{range}` braces and breaks template
substitution.

**Do not draw the subway from the basemap.** Protomaps only carries `kind_detail=subway` in
**z14 tiles** — verified by decoding z8–z14, all zero below 14 — so a basemap overlay
vanishes the moment you zoom out. Lines *and* stations come from
`public/data/beijing-subway.geojson` (committed), regenerated by `npm run fetch:subway`.

**Declare `backdrop-filter` alone, never beside `-webkit-backdrop-filter`.** Written as
sibling declarations, the CSS minifier collapses the pair and keeps only the prefix — which
Chromium doesn't support — so the blur silently never applies while the tint does. The
Safari prefix lives in its own `@supports` block where it can't be merged away.

**`:global()` does nothing in `src/styles/custom.css`.** It's Astro scoped-style syntax and
is silently dropped from a stylesheet loaded via `customCss`. Use plain selectors.

**Watch your own specificity.** `.sl-markdown-content p` (0,2,0) beats `.fl-strip` (0,1,0).
That has already caused one silent bug.

**Starlight icon names fail silently.** An invalid `icon=` renders *nothing*. Starlight has
no map/subway/passport icon — use `src/components/Ico.astro` for those.

**Never add `.nojekyll` to the repo root.** Pages publishes from `deploy.yml`, so nothing
runs Jekyll and the file has no job to do. It only matters if the Pages source setting ever
reverts to the legacy branch builder — and then it is actively dangerous. That builder fails
on the `---` fence at the top of any `.astro` file, and the failure is the only thing
stopping it publishing. `.nojekyll` makes it **succeed** instead: it publishes the repo root
verbatim over the top of `dist/`, and there is no `index.html` in the repo root. A red X on
`pages-build-deployment` means the Pages source moved back to "Deploy from a branch" — fix
the setting, never the symptom.

## Conventions

**Every page carries `last_verified: YYYY-MM`** and a `status` of `stub | draft | live`.
`src/components/PageTitle.astro` renders a quiet line from it, escalating past 12 months.
Pages transcribed from the 2024 handbook carry `last_verified: 2024-05` **deliberately** —
those facts were confirmed then, not now. Bump it only when someone has actually re-checked,
not when they reword.

**Structured data** (`src/components/Head.astro`) carries that date as `dateModified`, so an
AI summary can't present 2024 facts as current. That's the point of it.

**Map pins** live in `data/places.yaml`, one block each. Categories are fixed — adding one
means touching `places.yaml`'s documented list, `scripts/validate.mjs`, and the colour map in
both `BeijingMap.astro` and `custom.css`.

**Two maps, on purpose.** The Beijing map is MapLibre over our own pmtiles; the campus map
(`CampusMap.astro`) is plain inline SVG projected at build time from
`public/data/pku-campus.geojson`. A campus is one screen at one zoom, so tiling buys nothing
— and an SVG survives a screenshot, a print, and a browser pane with animation frames paused,
which is exactly where the WebGL map cannot be checked.

**Source documents live outside the repo**, in `../source-documents/` with a `CATALOGUE.md`
that logs what each one covers and which page it feeds. They're third-party copyright and one
is another student's personal report, so they stay out of git. The catalogue is the place to
look before writing anything factual.

## Brand

Crimson `#8e1b2c` → ember `#c0452a` gradients over SVG grain, cream `#f4ecdc` ink, warm
red-biased neutrals (never neutral grey). **Bodoni Moda** display + **DM Sans** body,
self-hosted in `public/fonts/`. Playfair Display was rejected — too soft for the source
posters, and its ampersand is an ornate Et-ligature.

The **frosted panel** material (our Liquid Glass interpretation) is on exactly two surfaces,
both chrome: the sticky header and the hero badges. Glass never goes under body text. It
ships with `@supports`, `prefers-reduced-transparency`, `prefers-contrast` and
`prefers-reduced-motion` fallbacks — all four required, not optional. Contrast was measured
against the worst-case content that can scroll behind, not a mockup.

The logo (`src/components/Logo.astro`) has **no "6"** (the guide outlives any cohort) and
**no PKU seal** (the university's mark, not ours to redraw).

## Commands

```bash
npm run dev              # localhost:4321
npm run admin            # local editing panel on localhost:4400 — 127.0.0.1 only, never deployed
npm run validate         # coordinate sanity + same-origin allowlist
npm run build
npm run fetch:subway     # regenerate the subway GeoJSON from OSM
npm run fetch:campus     # regenerate the PKU campus GeoJSON from OSM
npm run fetch:fonts      # re-vendor the typefaces
npm run make:og          # regenerate the link-preview image
```

**Overpass recipe that works:** `way["railway"="subway"][!"service"]` + `out geom`. The
`[!service]` is essential — yards, crossovers and sidings are 40%+ of results. Sending a
`User-Agent` is essential too, or you get blanket 429s. `relation[route=subway]; out geom;`
**always 504s** — don't retry it.

## Environment

Apple Silicon Mac, **no Homebrew, and no sudo available to the agent**. Node 24 and `gh` are
installed from official tarballs into `~/.local/` — use that pattern for any new tool rather
than asking for Homebrew. `~/Downloads` is TCC-blocked; files have to be copied into the
Desktop folder to be readable.

**The in-app Browser pane pauses `requestAnimationFrame` when collapsed.** MapLibre's style
loading is rAF-driven, so the map can *never* load there and fails silently — it looks
exactly like a broken map. Verify canvas/WebGL work in a real browser, or ask.
